# output 文件分类

`output/` 同时保存验收证据、交付记录、截图和工具输出。目录名本身不能判断某个文件可否删除；已有且被计划、交付或人工验收记录引用的证据可以保留。不要将整个 `output/` 加入 Git 忽略规则，也不要声称历史输出已经清理。Lint 与格式化工具跳过此目录，避免把历史源码快照当成活动代码或改写已有证据。

当前可直接查阅的证据入口包括：[T63 微信验收摘要](t63/wechat-validation.md)记录了实际操作、未通过项和人工补验入口；[T65 收尾检查](t65/final-checks.md)记录了交付门禁、证据文件和仍保留的工作区备份。各项证据按原计划或交付文档引用，不以截图或 Git 历史替代完整验收记录。

从本次开始，新增且可重建的本地执行输出放入 `output/local/`。该路径已加入 `.gitignore`；有长期复核价值的结论应记录在相应计划、交付或审计文档中，并链接到具体证据。保留既有目录时，按内容逐项识别用途，不因文件名包含阶段编号或 `output` 就批量迁移或删除。
