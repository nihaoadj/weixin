# 功能说明

## 结构化病例推理

学生可完成病史采集、问题表征、鉴别诊断、检查决策和初步处置五阶段。完成后获得信息采集、问题表征、鉴别诊断、证据推理、检查合理性、处置与安全意识六维评价，并能从最低分阶段开始重练。

## 学生端

- Demo 身份登录
- 医学问答
- 快捷问题
- 历史对话
- 学习报告生成
- 报告提交批阅
- 练习题列表
- 题目多轮作答
- 个性化学习画像与三项训练计划
- focused retry、动态微训练、跨病例迁移
- 正式六维成绩与练习掌握度分离复盘
- 站内通知与幂等已读

## 教师端

- 报告列表
- 报告详情
- 评分与反馈
- 题目新建
- 题目编辑
- 题目发布
- 题目详情
- 班级范围三级学情总览、病例下钻、学生档案
- 学生计划状态、目标维度、任务进度和练习掌握度只读展示
- 病例医学审核状态机与不可变审核历史

## 后端已具备接口

- Demo 登录
- 医学问答
- 对话保存和查询
- 报告创建、提交、批阅
- 题目创建、发布、查询
- 个性化计划、任务、微训练评分、通知和复盘接口
- 班级、医学审核和结构化病例分析接口

## 外部事项

- 真实 AI 地址、密钥和模型名仍由部署环境提供；自由问答和结构化任务均通过服务端调用，带一次重试、审计和确定性兜底。
- 微信登录的服务端 `code2Session` 链路已实现；正式上线仍需配置 AppID/AppSecret、合法域名、教师白名单和生产部署，并完成仓库外医学专家签署。
