## 2. P0 安全与身份

- [ ] **阻断** 仓库历史处置完成，已暴露密钥已撤销和轮换。
- [ ] **阻断** 客户端包、Source Map、日志和配置扫描不到有效密钥/令牌。
- [ ] **阻断** 所有模型请求来自服务端 AI Gateway，客户端不能直连供应商。
- [ ] **阻断** 服务端从可信微信上下文解析身份，不接受客户端自报 openid/userId/role。
- [ ] **阻断** 教师和管理员角色由受控流程授予，普通用户不能自选。
- [ ] **阻断** 学生跨账号、教师跨班级/课程、ID 枚举越权测试全部通过。
- [ ] 账号冻结、角色撤销、班级移除在目标生效时间内生效。
- [ ] 管理操作启用强认证/MFA（如有管理后台）。
- [ ] 数据库、函数、存储和密钥权限完成最小权限复核。
- [ ] Secret、依赖漏洞、SAST 结果无未接受的高危项。

## 3. 数据与一致性

- [ ] **阻断** 数据库 migration 已在 staging dry-run、执行并校验。
- [ ] **阻断** conversation/submission/report/review 使用统一业务 ID，无 `_id` 混用。
- [ ] **阻断** 提交、报告生成、评分发布通过幂等和重复点击测试。
- [ ] **阻断** 多教师并发批阅使用乐观锁，不会静默覆盖。
- [ ] 合法 0 分、边界分和非法分测试通过。
- [ ] 列表使用 cursor、limit、稳定排序和 scope 条件。
- [ ] 索引已部署，关键查询在接近生产数据量下无不可接受慢查询。
- [ ] 客户端本地存储只是缓存/草稿，换设备与清缓存不丢已提交数据。
- [ ] 退出登录/换账号不会读取上一用户敏感缓存。
- [ ] Demo 模拟 openid、硬编码题目和样例健康数据未进入生产。

## 4. 核心业务

- [ ] 教师创建 → 审核 → 发布 → 目标学生可见 E2E 通过。
- [ ] 非目标学生不可见；过期/关闭作业不能新建作答。
- [ ] 学生多轮作答、切后台、断网恢复、跨设备续答通过。
- [ ] 会话只保存一条会话实体，不重复创建完整历史快照。
- [ ] AI 报告生成失败时保留作答并可安全重试。
- [ ] 学生提交 → 教师筛选/详情 → 评分/反馈 → 学生查看 E2E 通过。
- [ ] 退回修改、重新提交和最终归档（若本版本包含）通过。
- [ ] 缺失页面、未注册路由、组件声明和静态资源自动检查通过。

## 5. AI 与医学安全

- [ ] **阻断** 产品和所有 AI 页面明确标识“AI 生成/医学教育用途”。
- [ ] **阻断** 明确不替代医生、诊断、处方或急救，文案经医学/法务审核。
- [ ] **阻断** 胸痛、呼吸困难、意识障碍、自伤/他伤等高风险黄金集达到批准门槛。
- [ ] **阻断** 个体化用药、停药和高风险诊疗请求不会产生危险建议。
- [ ] **阻断** 模型返回非法 schema、超时、拒绝或不可用时安全降级，不伪造报告。
- [ ] 输出引用可定位且支持关键结论；过期/无来源时明确不确定。
- [ ] 模拟患者持续标明 AI 身份，不冒充真实医生/患者。
- [ ] 提示注入、系统提示提取、跨用户数据诱导、越狱红队测试通过。
- [ ] 报告保存模型、提示词、知识库、量表和安全策略版本。
- [ ] 模型/提示词/知识库候选版本通过固定回归集，并可一键回滚。
- [ ] 医学专家完成题目、患者卡、安全模板和黄金集签字。
- [ ] 用户可举报不准确/有害内容，工单和人工复核链路可用。

## 6. 隐私与合规

- [ ] **阻断** 已确认服务是内部教学还是面向公众，并形成适用性结论。
- [ ] **阻断** 隐私政策、用户协议、AI 使用说明与实际数据流一致。
- [ ] **阻断** 医疗健康敏感个人信息的单独同意、撤回和证据记录可用。
- [ ] **阻断** 若包含未成年人，年龄识别、监护人同意和专门保护已确认。
- [ ] **阻断** 模型供应商的数据用途、保存、训练、地域、子处理者、删除和事件通知已评估/签约。
- [ ] **阻断** 模型备案/应用登记、公示、安全评估和 AI 内容标识要求已由法务确认。
- [ ] 数据清单、分类分级、处理目的、保存期限和 owner 已批准。
- [ ] 输入前提示避免填写真实身份/病历标识，服务端脱敏按策略运行。
- [ ] 用户查阅、导出、更正、删除、注销流程已演练并留证。
- [ ] 删除覆盖主库、索引、缓存、导出、供应商和备份淘汰流程。
- [ ] 个人信息保护影响评估/数据处理评估完成并归档。
- [ ] 投诉举报入口、处理时限和责任人已公开/配置。
