# 当前产品合同

本页定义现行业务行为；实施状态与后续方案见[计划索引](update_plan/README.md)。

## 研讨、回应与证据

- 课堂 PBL 由教师预建并绑定其拥有班级，学生 participation 独立按 `problem_framing → hypothesis → evidence → synthesis → completed` 推进。阶段证据来自本阶段开始后的学生消息，服务端仅允许相邻推进；AI 讲解不能冒充学生证据或自行推进诊断。进行中课堂尚无 participation 时，首条消息仍可创建参与记录。
- `guided | direct` 是逐消息的“探究引导 / 直接讲解”，新研讨默认 guided。切换只影响下一条未提交消息，保留草稿和会话；幂等身份包含内容与方式，消息/快照保存自身方式，participation 只保留最近生效方式。`learning_response` 由服务端确定性渲染为“回应 / 关键要点 / 下一步”。
- 完成时冻结唯一 `completion_snapshot_id` 与 `evidence_completed_revision`。服务端确定消息的 `evidence | private_follow_up`；后续私人续问仅本人可见，使用独立 provider schema/result，不创建诊断、建议题、教师工作项或学习证据。已完成课堂后来关闭仍可私人续问，未完成的关闭课堂拒绝写入。
- 自主 PBL 可无班级且永久私有，不再提交教师；旧共享快照只读兼容。自主路线与AI测试须明确未教师审阅标记，其结果仅本人可见，不进入教师查询和统计。

## 学习路线、最终测试与教师审阅

- 四阶段研讨完成时，同事务冻结分析并创建唯一学习路线与测试shell；后台分别生成，失败不倒回已完成研讨，可恢复原对象。路线生成后直接发布，本人按顺序完成资料和AI合成病例，不需要教师审阅路线。
- 资料使用冻结的可追溯来源与AI导读；阅读心跳只累计受限前台时间，由学生手动确认完成，不设最低阅读时长。合成病例按病理识别、机制解释、证据判断、总结反思四阶段推进；开场展示该病例已冻结的阶段目标与提示，已完成阶段可回看，共享同一会话历史，按阶段显示消息，完成条件达成后解锁下一阶段，不计分；安全分流和证据不足不能放行。
- 新建课堂与自主研讨各选一个知识目标；历史多目标研讨和已发布的三道单选测试保持原格式及评分规则。每份新路线仅一个五题最终测试，固定为3道单选、1道多选和1道简答。课堂由有权教师在原流程中审阅固定分析及同一测试草稿，可编辑答案、解析和简答评分要点，保存、要求修改并开放，不新增人工判分步骤；自主测试由AI直接开放，永久私有。路线学习可先于教师审阅，服务端同时验证学习完成与测试开放条件。
- 开放后题目、参考答案、评分要点和版本冻结；本人可保存混合题型草稿，整份一次提交后锁定答案。单选各15分，多选完全匹配得25分，简答由模型依据冻结参考答案及三个各10分的要点评分；评分失败保持待判分并可重试，不记作0分。判分完成形成唯一结果，展示各题得分和总分；0分也完成，未交或待判分不产生最终成绩。不设达标线、补考、第二轮或测试后自动补强。
- 结果页上部一次展示一道题及其作答、答案、解析，可左右切换；下部为整卷共享的一条导学助手对话。每条提问绑定发送时的题号，切题不清空历史；助手默认围绕绑定题目回答，明确提问时可跨题比较。完整消息与摘要保存在服务端，助手不改成绩或冻结答案。
- 教师课堂进度按已发布路线统计，成绩与正确率仅来自已提交课堂最终测试；自主、过程对话和独立病例不进入该统计。教师可读取原归属课堂历史事实；离班或归档后禁止新开放，已发路线与已开放测试仍归原学生。
- 教师题库独立保存去标识化题目副本，可查看、搜索、编辑和删除；明确入库不嵌入测试开放事务，副本修改不改变已开放测试，不提供组卷或全班发布。
- 旧任务包、轮次练习、建议题采用和二轮入口退役；旧写入统一冲突，特定旧资源读取404、旧集合为空。普通问答报告写入及教师批阅继续退役。

## 教师工作区

教师主导航为 PBL、学情、内容，教师默认进入 PBL；三个原根入口均承载连续切换容器，工作区筛选按用户隔离；PBL、总览、知识与推理、学生、内容按顺序左右切换，真实相邻正文预先初始化并同时参与拖动过渡。容器内切换不重新打开根页，详情返回保留当前工作区；学情三面板共享统计范围。旧待办根地址兼容跳转到 PBL，历史工作区参数仍规范化到对应根页。

PBL 根页聚焦创建、关闭具体课堂、四项进度统计与研讨完成学生列表，不设测试待处理分栏；选用当前教师可使用的完整病例；教师保存后即可选用，无独立医学审核或发布步骤。学生记录通过“查看固定诊断”读取研讨分析，通过“查看最终测试”在同一测试页保存、反馈退改、恢复生成或开放。课堂下拉菜单的跨课堂测试待办进入独立二级列表后处理具体测试，保留跨课堂定位能力。固定诊断是测试审阅依据，不再独立审批；逐学生成绩与分析通过“查看课堂学情”进入学情。课堂关闭与班级归档、学生离班分别处理：历史事实可读，详情由服务端投影当前班级/成员范围是否活动，范围失效后不得继续审阅写入。

学情只读查看授权班级、课堂、学生与日期范围内的总览、知识与推理、学生及完整结果。进度并入学生行，旧 `progress` 入口/偏好在学情根页映射为学生。顶部副标题打开统计日期弹层，默认最近30天。研讨参与按开始时间、路线进度按发布批次截至查询时间、成绩按测试完成时间、诊断按有效研讨完成时间分别统计，日期使用北京时间；各批次分母独立，0 与无样本分开。概况统计条区分已发布路线与该批次已完成测试，不作为区间平均分样本数。总览知识点按最低有效指标升序预览三项，得分较低学生从完整范围学生摘要中取平均分最低三名，null不排名、0参与。多班级学生详情先选明确班级。诊断按知识点/推理维度展示去重人数，展开各学生自己的摘要，不将一名学生描述代表全组。未完成研讨且尚无路线的学生仍可查看阶段；Demo 历史参与缺少开始时间时保留只读记录并标明时间未提供，不补造日期或参与计数。知识指标为客观题正确率及简答得分率，不宣称掌握度，推理问题不虚构评分。汇总不含完整作答，结果详情按需授权读取，展示混合或历史格式冻结事实，不进入学生导学会话、不改分。

内容仅保留病例库和个人题库，默认病例库；普通资源列表只提供搜索、查看/编辑和删除，不显示草稿、审核、发布或归档状态。本人完整病例保存后即可选入新课堂，系统病例只读；编辑原记录，不自动克隆或送审。病例作者权限由服务端独立验证，UI消费当前edit/delete投影。个人题库从已保存、授权且摘要匹配的单选来源去标识化导入，随后编辑或删除独立副本；来源测试无需已开放，副本不回写原测试，不提供组卷或全班发布。删除资源只移出活动库，无归档/恢复入口；已有课堂快照、独立病例训练快照、作答和冻结测试保留，新选用不得使用已删资源。

开放讨论问题、教师补充知识卡和独立三题小测/到期复习退出活动流程。旧问题及卡片、复习项和证据保留原数据，不进行清库；旧问题/线程详情404、旧活动列表及卡片/复习队列为空，旧创建、编辑、提交、审核、发布、作答及复习写入409 `RETIRED_FLOW`，身份和角色校验继续执行。旧教师问题编辑/知识卡地址回病例库，旧学生问题详情回病例列表；旧复习地址有有效知识点时进入知识节点，否则回学习首页。学习首页“知识点学习”进入知识节点或知识图谱，不再宣传三题复习；节点继续开始研讨或查看当前学习路线。知识图谱保留目录及现有知识状态投影；当前AI路线、最终测试与结果导学不增加独立复习步骤。

独立测试队列按待审、退改与可重试生成异常分类。旧资源审批摘要字段兼容归零，不再制造病例审核/发布待办；旧问题和卡片计数字段也为零。题库没有对应处理动作的状态不制造待办，读取失败显示未知。

## 学生学情

学生学情保留现有首页结构，通过本人范围的实时投影串联参与研讨、学习路线与最终结果，不再读取退役的轮次任务报告。最近记录按当前进度进入研讨、学习计划或结果解析和共享导学；回到页面重新读取。

本周与近四周趋势只展示北京时间自然周内已完成最终测试的平均得分，不宣称知识掌握度。未提交、待判分或评分失败没有成绩，真实零分仍计入。仅在两周都有样本时比较分数差。课堂与自主结果均可在本人页展示，不因此改变自主数据的私有性或教师统计范围。

四个指标为累计阅读心跳时长、全部路线最终测试完成率、有完成结果的目标去重数量、有效研讨完成诊断次数。没有掌握阈值，不把“已测知识点”当成已掌握；时长不覆盖研讨、病例或答题，也不声称本周累计。

薄弱点由有效完成诊断的知识缺口、推理问题与最新已完成测试更新。后续测试满分可移除此前同目标知识缺口，非满分作为巩固依据；新诊断不能被更早测试清除。推理问题无量化得分。诊断总结引用已有结构化诊断并结合真实进度，不新增模型诊断或假增长指标。

## 范围、内容与知识库

授权与DTO投影见[安全](security.md#服务端授权)；学情局部失败不得遮挡仍可读取的本课内容。

内容页承载正式病例与个人题库，教师个人病例保存即教学可用，旧病例医学审核/发布及教师补充卡审核链退出活动流程，历史审核记录保留。研讨schema v8不生成建议题、候选任务或知识补充卡审核链。个体学习路线内容直接可学，不等同于公共资源发布或专家签署。

聚焦树与全树消费同一持久化边集合，聚焦树列出视野外跨主题前置。运行目录边界见[架构](architecture.md#证据与统计)，节点、关系及公开来源见[知识库](knowledge-base/README.md)。

## AI 与独立病例

AI合同经运行时schema校验，schema v8区分`knowledge_gaps`、`reasoning_issues`、学生回应与安全提示；路线、测试、病例反馈使用三个独立严格任务信封，失败不fallback，不伪造诊断。提供方、外发和审核规则见[安全](security.md#ai与医学审核)。

独立结构化病例保留病史采集、问题表征、鉴别诊断、检查决策、初步处置五阶段及六维学生训练分析；正式评分由确定性规则控制，AI 反馈不得覆盖分数或 evidence。
