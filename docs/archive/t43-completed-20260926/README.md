## 产品目标

课堂对话完成后形成诊断审阅单；教师在同一详情审阅完整两轮任务包，一次发布给该学生。每名学生每个课堂只有一个任务包，任务按课堂知识节点组织。任务包进入终态后生成唯一最终报告，进入 PBL 巩固跟进。教师学情恢复学生综合详情，仅汇总已完成课堂任务包。教师可将审阅题目独立存入自己维护的题库，本期不提供题库组卷或全班发布。

独立病例保留学生训练分析，不形成教师报告。自主研讨、私人续问及未审核个人练习继续私有。教学审阅不替代病例和知识补充卡的医学审核。
