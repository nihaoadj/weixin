# 03 页面与导航

状态：计划目标。遵循既有蓝白临床教学记录风格、原生标题及“页面 → 模块 → 记录 → 字段”层次，不新增全局视觉系统。

## 页面职责与入口

| 页面           | 内容/主要动作                                                     | 返回及上下文                     |
| -------------- | ----------------------------------------------------------------- | -------------------------------- |
| 教师 PBL 首页  | 保留班级、课堂 picker 与诊断/巩固分段；课堂摘要增加“查看任务进度” | 保持班级、课堂、分段             |
| 诊断详情       | 学生与课堂 → 证据/发现 → 两轮任务编辑 → 发布范围与反馈            | PBL 诊断分段；从待办进入则回待办 |
| 课堂任务进度   | 当前课堂每人未发布/进行中/逾期/已完成，必要计数                   | PBL 当前课堂；进行中不跳最终报告 |
| 巩固详情       | 本课结果 → 节点/维度 → 两轮轨迹 → 任务证据摘要                    | PBL 巩固分段；移除近30天综合模块 |
| 教师学情       | 保留总览/学习进度/知识掌握，恢复“学生学情”页内标签                | 一级导航仍为学情                 |
| 学生综合学情   | 身份、日期筛选、完成课堂数、逐目标结果、历史最终报告列表          | 学情学生列表；列表状态恢复       |
| 教师内容/题库  | 新增“我的题库”入口，类型/节点/状态筛选和分页                      | 内容首页                         |
| 题库详情       | 题干、答案解析、标签、版本、医学状态；编辑/归档                   | 题库列表；无发布或组卷按钮       |
| 学生学习首页   | 正式待办一课堂一条；个人资源入口单独保留                          | 学生一级导航                     |
| 学生任务包详情 | 班级/课堂/期限、当前轮次、节点分组、下一任务                      | 学习首页或所属课堂               |
| 病例训练分析   | 本次反馈、维度、下一步；任务病例提供“返回课堂任务”                | 正式任务回包，独立病例回病例列表 |
| 学生学习记录   | 过程记录继续可读；终态后提供最终报告                              | 学生学情；不恢复提交教师按钮     |

新二级页面由导航平台统一注册：teacherPblProgress、teacherQuestionBank、teacherQuestionBankDetail、studentClassroomPackage。现有 teacherAnalyticsStudent 路径恢复综合详情；teacherPblFollowUp 路径使用 reportId。实际 URL 注册写入 pages.json 与路由测试，不在 Vue 拼接字符串。

教师综合列表来自有权班级成员与历史正式报告主体并集。无报告学生仍可列出“尚无完成课堂报告”，不从个人学习推断表现。默认最近 30 个自然日，按上海时区筛选报告 completed_at，可改日期。只读历史报告详情必须再次授权。

## 诊断整包编辑

首屏识别学生、课堂、诊断状态；整包审阅为唯一主要操作区。按知识节点列同类记录，每题可展开首轮/第二轮内容；“加入我的题库”是次级动作。独立的两轮总览标示未审阅、缺资源和医学审核阻塞数量。

每次保存成功返回新版本；本地未保存编辑先提示保存再入库/发布。教师显式勾选“已核对两轮全部题目及评价依据”，其确认绑定版本，任何编辑清除确认。主按钮“发布任务包”确认框显示固定学生、课堂、首轮任务数和第二轮条件，成功转只读。返回时有未保存内容提示保留或放弃；网络失败保留输入。

## 展示与交互规范

使用既有 med-page、med-surface、med-border、med-brand、med-navy、med-muted 语义令牌。中文系统字体；模块标题与记录标题至少在字号/字重/位置中有两项区分。模块 24–32rpx 间距、24rpx 内边距，同类记录分隔，最多一个强焦点，不给每道题套大阴影卡。

固定发布栏需安全区和等高底部留白，键盘出现不遮输入；44px 触达区、主要提交48px，长题干自然换行。窄屏单列，宽屏只改善阅读宽度与对照，不改信息顺序。没有新视觉方向，因此无需新增素材或另选设计系统。

## 状态矩阵

| 状态                 | 必须可见的行为                                     |
| -------------------- | -------------------------------------------------- |
| 加载                 | skeleton/加载说明，不显示上一个学生的操作区        |
| 无诊断/无报告/空题库 | 分别说明生成条件，不补造结论；题库指向诊断审阅     |
| 局部加载失败         | 证据、题库动作失败不清空其他已加载内容；独立重试   |
| 版本冲突             | 提示重新加载最新草稿；不自动覆盖教师修改           |
| 审核阻塞             | 列出具体资源与原因，发布禁用，合法审核入口可达     |
| 发布结果网络未知     | 使用原幂等键重试/查状态，禁止新建第二份包          |
| 长题、多节点、多报告 | 分页/折叠可达，滚动到底操作不被底栏挡住            |
| 未授权/无效深链      | 不泄露资源是否存在，明确返回正确工作区             |
| 最终报告待修复       | 保留任务已完成事实，显示报告暂不可用；不展示假报告 |

课堂进度逐学生列表已接入第 05 册独立只读接口及局部页面；新增接口的定向测试和前端类型/行为测试已通过，但真实微信点击、筛选、分页及报告返回路径未完成验收。不能以聚合计数推断某名未发布或进行中学生的状态。巩固跟进只列有最终报告的本课学生，报告缺失提示留在课堂进度，不以旧计划详情冒充本课报告。

旧路由映射、无栈返回和 planId 兼容规则见第 07 册。加载令牌按班级/课堂/学生切换失效，写后使相关列表、任务与学情缓存失效。
