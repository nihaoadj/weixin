# 02 产品流程

状态：以下全部为 T43 计划目标。

## 产物及受众

| 产物         | 生成时点                 | 使用者                       | 教师统计     |
| ------------ | ------------------------ | ---------------------------- | ------------ |
| 过程学习记录 | 对话和作答进行中         | 学生本人；课堂看板仅必要进度 | 不作为结果   |
| 诊断审阅单   | 课堂四阶段证据充分并完成 | 对应学生、有权教师           | 不计达标     |
| 课堂任务包   | 教师集中审阅后一次发布   | 对应学生                     | 只计进度     |
| 病例训练分析 | 单次病例完成             | 学生本人                     | 不独立进入   |
| 最终学习报告 | 任务包终态               | 本人、有权班级教师           | 唯一结果来源 |
| 教师题库题目 | 教师明确点击加入题库     | 该教师                       | 不进入       |

## 正常闭环

1. 教师创建课堂，选定非空课堂目标节点集合（保持现有最多 3 个目标限制）。目标必须来自 active catalog，发布前后都不把其他课堂同编码任务合并。
2. 学生完成四阶段讨论；服务端固定完成快照。课堂诊断单只对应此学生此课堂，后续私人续问不改诊断。
3. 系统形成两轮任务草稿。有薄弱点时针对目标补强；无明确薄弱点时验证课堂目标。推理训练必须同时关联至少一个课堂目标节点及能力维度。
4. 教师打开诊断详情，核对证据摘要、首轮与第二轮题目、答案解析及评价规则。可编辑、删除非必需候选，保存草稿；每个必需目标必须保留完整两轮覆盖。不能删除课堂目标或已确认的必需推理目标来规避验证。
5. “发布任务包”提交当前版本；服务器再校验成员、审核和覆盖，原子创建唯一个人任务包、冻结版本及通知。形成性反馈为可选字段，不强迫教师输入无意义文字。
6. 学生学习页出现一条课堂任务包，包内按知识节点浏览；多节点题只在主节点出现，其他节点显示关联，不重复计完成量。当前轮按固定 position 顺序执行。
7. 最后一项必需任务完成后自动评价。首轮通过则结束；失败只激活失败目标第二轮，已通过目标不重做；第二轮完成后无论是否达标都形成最终报告。
8. 最终报告进入 PBL 巩固跟进，并由同一份持久化结果进入教师综合学情。无需学生再次提交，无需教师再次评分。

## 边界流程

- 证据不足：继续当前阶段，不得把无薄弱点误判为证据充分；不可发布。
- 对话完成而资源构建失败：诊断仍可读，任务草稿标记失败，教师可重试构建；不重开对话。
- 医学审核未满足：保留草稿和阻塞项，允许去对应医学审核入口；禁止发布。
- 教师仅反馈：诊断仍可继续整包审阅；教师明确关闭未发布诊断则不生成任务和最终报告。
- 课堂关闭：未完成讨论沿用现有拒绝规则；已发布任务仍可按本人授权完成，已完成讨论仍可私人续问。
- 学生退出班级或班级归档：禁止新发布；已发任务由本人继续完成。有权原班级 owner 可读该班历史正式报告，不因学生换班向新班级外发。
- 逾期：显示逾期但允许继续；不记零分、不自动结束或生成报告。
- 未发布、零题或存在未完成任务：不能生成最终报告。
- 同一课堂已有旧版计划：教师侧保留旧版只读记录，未完成旧PBL计划仍允许学生从“历史任务”继续原有执行，禁止与新包并行创建；处理见第 07 册。
- 独立病例的练习反馈保留，新的自动个性化计划不进入正式待办；本期停止独立病例完成后自动创建旧 case_assessment 计划，历史计划只读回看。
- 题库入库与发布是独立动作，任一步失败不自动回滚另一已成功动作，也不自动入库。

## 示例

同一课堂目标为 A、B，学生甲有 A 薄弱和证据推理问题。教师审阅一份包，包含 A 的巩固/再测、B 的目标验证，以及关联 A 的推理练习，两轮资源都完整。甲首轮 B 通过，A 与推理失败，第二轮只继续 A 和推理；最终报告仍是一份。学生乙无明确薄弱点，收到其个人 A、B 验证包，结果独立；任何学生都看不到对方诊断。
