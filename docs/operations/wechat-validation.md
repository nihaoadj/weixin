# 微信开发者工具前端验收

微信小程序是唯一产品目标。T01–T25 阶段概况见 [阶段概述](../update_plan/01-25-summary.md)；未完成的开发者工具验证必须明确标为待验收，不能由历史 H5 结果补足。

## 开发环境

在仓库根目录执行：

```powershell
$env:VITE_APP_MODE='demo'
npm run dev:mp-weixin
```

保持 watcher 运行，等到 `Build complete. Watching for changes...`。开发者工具只导入 `D:\CODE\weixin\wxprogrom7.15\dist\dev\mp-weixin`，随后执行普通编译。`build:mp-weixin` 的生产目录不能刷新开发目录。

## 自动化连接诊断

先在开发者工具完成登录，启用本地自动化所需服务端口。不能关闭域名安全校验、清理工具 storage 或手改 dist。

```powershell
$env:WECHAT_CLI_PATH='开发者工具安装目录\cli.bat'
$env:WECHAT_AUTO_PORT='9420'
& $env:WECHAT_CLI_PATH auto --project 'D:\CODE\weixin\wxprogrom7.15\dist\dev\mp-weixin' --auto-port 9420
npm run test:mp:doctor
```

`test:mp:doctor` 只验证本地路径、安全配置、CLI 帮助和自动化握手；其通过不等于用例、普通编译或页面通过。CLI 可能在 JSON 错误 `code 10` 时仍退出 0，必须同时检查结果，不能只看退出码。缺 `SDKVersion` 表示基础库/模拟器尚未就绪，不能跳过 SDK 版本检查。

## 选择验收范围

默认是**受影响流程验收**：一次页面、组件、文案、布局或局部导航改动，只运行对应的最小自动化脚本或手工流程，并从受影响页面取得当次后台截图。不要因为局部改动自动运行完整学生、教师、病例和 PBL 回归。

仅在以下情况运行**完整核心回归**：发布候选、共享导航/应用壳/构建改动、跨模块数据或身份改动、局部验收发现影响外溢，或用户明确提出。核心和专项脚本以当前 `package.json` 为准；所有脚本复用同一个已打开的开发者工具，必须串行；不得为运行脚本新开工具窗口、重登、抢占前台或清理工具数据。

## 交互与渲染

- 交互：真实点击、输入、提交、返回、刷新后状态及防重复操作；不得以 `setData` 或调用业务方法代替被测交互。
- 渲染：实际控件及文字可见，布局无重叠/遮挡、滚动到底可操作、固定栏正确；检查长内容、加载、空、失败状态和有代表性的模拟宽度。
- 截图：来自当次开发者工具实际页面的内部截图接口，后台运行，不依赖系统截屏、窗口置前、鼠标或键盘焦点；逐张审阅。截图比较只证明稳定性。不要自动接受新基线或输出完整学生答案/隐藏病例。系统截图仅限用户明确要求查看工具窗口时使用，不能充当自动化验收截图。
- 模式：Demo 证明确定性界面合同；服务端权限和 API 不回退仍由独立受管测试验证，不能称作已完成小程序 API E2E。

## 完成口径

| 证据                         | 允许结论                               |
| ---------------------------- | -------------------------------------- |
| 格式、类型、Vitest           | 被覆盖逻辑/组件行为正常                |
| 小程序生产构建               | 可生成小程序产物                       |
| SDK 握手                     | 工具协议连接就绪                       |
| 开发者工具操作及实际截图审阅 | 所测状态在该工具/基础库/模拟宽度下通过 |
| 未执行真机                   | 本次不包含真机结论                     |

缺登录、缺自动化服务、编译未完成、用例失败、未审阅截图均为待验收。记录源码版本/工作区、模式、命令、构建完成时间、开发目录、普通编译、工具/基础库版本、角色/入口、流程、截图路径、失败与解除条件。

桌面 runner 尚未部署。Ubuntu 静态 CI 或本地单元测试通过不能替代本节验收；不得给未运行的开发者工具测试标绿。真机按用户要求本次不执行，生产发布条件仍需另行验证。
