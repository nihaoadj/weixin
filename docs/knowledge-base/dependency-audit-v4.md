## 关键纠正

- 删除“坏死 → 凋亡”：二者是不同细胞死亡模式，不把一种画成另一种的普遍前置。
- 将“可逆性损伤 → 缺氧/氧化应激”改为“缺氧/氧化应激 → 可逆性损伤”：机制应指向可能结局。
- 将“血管反应 → 炎症介质”改为“炎症介质 → 血管反应”，并增加“炎症介质 → 白细胞募集”。
- 删除“急性炎症 → 慢性炎症”：慢性炎症可从起始即为慢性，不是急性炎症的必然下一步。
- 删除“细胞适应 → 组织再生”：适应不是再生的通用前置。
- 删除“淤血/缺氧 → 休克”：休克通常是低灌注导致组织缺氧，而非由这两个节点反向定义。
- 增加“慢性炎症 → 纤维化”“充血与淤血 → 水肿”“血栓形成 → 梗死”等来源直接支持的关系。
- “坏死 → 梗死”用 NLM MeSH（S14）直接核对缺血性坏死的定义；它是定义上的学习前置，不表示坏死导致血流阻断。S14 同时逐边支持血栓/栓塞 → 梗死，但不表示每个血栓或栓塞都必然造成梗死。
