# T08-01 产品学习闭环

## 学生流程

1. 学生自由问答，或从知识地图、错题本、病例报告进入问答并携带一个主知识点和至多两个关联知识点。
2. 聊天页显示当前学习主题；切换主题仅作用于后续消息。没有主题仍可正常问答。
3. 学生可把助手回答、报告建议或教师反馈加入复习。无主题时，学生必须先从目录中确认知识点；私人备注上限 300 字。
4. 结束问答时，系统可从已确认主题抽取 1～3 道未重复的单选题。跳过不计错；答错生成薄弱证据。
5. 学习首页显示到期复习、知识地图和错题本。学生可从薄弱点再次发起带上下文问答，或从复习结果进入关联病例。

## 知识状态

| 状态 | 判定 |
| --- | --- |
| 未开始 | 无可靠学习证据 |
| 薄弱 | 最近客观卡答错，或存在低于 70 分的病例/微训练证据 |
| 学习中 | 已有复习记录，但最长稳定间隔不足 21 天 |
| 待复习 | 存在到期卡片 |
| 相对稳定 | 无逾期卡、最近无错误且稳定间隔达到 21 天 |

浏览页面或打开卡片不改变状态。教师聚合只使用客观小测、病例、微训练与教师标记，不使用私人备注或回忆卡自评。

## 教师流程

- 教师在系统只读目录下为自己拥有的班级补充卡片。
- 教师批阅问答报告时可选择“建议复习知识点”。
- 审核者使用现有医学审核权限审核教师卡片。
- 教师在学情页查看本班到期积压、参与人数、客观正确率和薄弱知识点，不查看私人文本。
