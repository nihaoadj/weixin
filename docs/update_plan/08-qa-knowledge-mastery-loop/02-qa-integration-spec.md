# T08-02 问答主体联动规格

## 对话上下文

- 每个对话可保存稳定知识点代码和来源：学生选择、题目/病例绑定、学生确认的模型候选。
- 普通问题和病例由教师在内容侧绑定知识点；从其进入的问答线程自动继承上下文。
- 聊天请求携带已确认的公开知识点代码；服务端验证代码存在且学生可见后才回显。
- 对话历史支持按知识点筛选，但保持现有分页、报告和教师批阅行为。

## 结构化问答响应

保留现有字符串兼容入口，并新增结构化响应：

```text
answer
safety_notice?
learning.confirmed_topic_codes
learning.candidate_topic_codes
learning.follow_up_prompts
```

当前候选仅来自确定性上下文。未来模型候选必须由服务端限制为目录内代码，并经学生确认；模型不得返回或修改分数、正确答案、复习状态、隐藏病例字段或完整历史学生答案。

## 结束小测

- 创建小测时只取可见、已审核的 `single_choice` 卡片；题面不包含答案或解析。
- 提交后才返回正误、解析和下一次到期时间。
- 已答错卡进入复习项；已答对卡仅更新调度。
- 小测和复习均可在 API/Demo 模式使用，且不允许请求失败时切换数据源。

## 隐私与安全

- 日志只记录路由、状态、耗时、卡片/知识点代码和错误类别，不记录 prompt、完整回答或私人备注。
- 问答上下文只能由对话所属学生读取；教师只读取聚合统计。
- 问答内容不作为医学诊疗建议，页面继续显示既有教学与安全提示。
