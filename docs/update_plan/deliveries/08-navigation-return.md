## 实施结果

- 主导航改为原子 `reLaunch`，不把不同主工作区混入同一返回栈；详情、替换、根路由和返回均有重复触发保护和失败 toast。
- 新增 `backOrRoute` 与 `handleBackPress`：有足够历史时正常 `navigateBack`，无历史、栈不足或返回失败时重启到页面指定的业务入口；原生标题栏/实体返回键只拦截用户动作，不递归拦截 `navigateBack`。
- 18 个二级页注册原生返回回落。病例相关页回病例列表，学习子页回学习首页或原学习任务，聊天报告回聊天，教师页回对应的工作台栏目、审核队列或学情首页。
- 保留完成态流程的 `redirectTo`：病例训练完成后报告返回病例列表；从学习计划启动的病例任务最终回学习首页。微训练改为详情栈并携带 `planId/taskId`，可以稳定回计划。
- 问题编写、病例编排、病例训练和微训练在有未保存输入时要求确认离开；保存/提交中阻止离开。问题和病例编辑器以实际表单快照建立已保存基线，保存成功后更新基线。
- 加载失败、缺少路由参数和资源不存在时均提供可见的返回入口，不再仅显示不可操作的重试。
