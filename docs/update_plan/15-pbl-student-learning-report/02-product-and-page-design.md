# 产品与页面设计

## 报告生命周期

报告按当前学生和 PBL session 聚合，状态优先级为：

1. 有活动计划时为 `learning_cycle_1` 或 `learning_cycle_2`；
2. 所有计划完成且任一计划耗尽时为 `support_needed`；
3. 所有计划完成且全部改善时为 `improved`；
4. 个人讨论完成但没有学习计划时为 `awaiting_learning`；
5. 其余参与过程为 `discussing`。

学生未参与讨论但收到同课堂任务时也生成报告。此时不显示个人薄弱点，将任务标为“课堂共同训练”。同课堂存在多个计划时全部纳入详情；只要仍有活动计划，报告保持学习中。

## 确定性说明

- `discussing`：说明当前阶段和最新缺失要素，下一步进入课堂继续讨论。
- `awaiting_learning`：说明学习线索已形成，后续学习待教师审阅发布。
- `learning_cycle_1/2`：说明当前轮次、已完成任务数和未达标目标，下一步进入任务页。
- `improved`：说明所有必需目标已满足对应阈值。
- `support_needed`：列出仍未达标目标，说明自动轮次结束并建议结合线下支持。

模板只使用学生 DTO 中的状态、目标标签、阈值和成绩，不调用 AI，不推断医学诊断。

## 学情总览

- 页首以“我的病理学习档案”说明当前最重要的下一步，不使用综合分。
- “闭环分布”以分段条和明确数量显示六种状态。
- “反复出现的学习重点”只统计本人 ready 诊断中相同知识点或推理维度的出现次数。
- “最近 PBL”按最近活动时间列出课堂、状态、目标完成数和详情入口。

## 单课详情

- 课堂抬头：病例、病理主题、开始时间和当前结论。
- 四阶段证据轨道：阶段状态、证据摘要、当前缺失要素；没有个人参与时显示明确空态。
- 本次学习线索：知识薄弱点与推理问题分组，展示本人证据摘要和改进方向。
- 目标改善对照：按 plan 和目标显示第一轮、第二轮、阈值、证据和达标结果；未激活、跳过和缺失分别显示文字状态。
- 判定时间线：讨论完成、任务发布、每轮评价和最终结论。
- 行动入口：继续讨论或进入任务页；完成态只提供回看。

## 视觉与交互

主导航调整为 `课堂｜任务｜学情｜知识｜答疑`。学习记录改为答疑页二级页面，答疑页以详情导航进入，历史页支持返回答疑。

页面沿用现有医学设计令牌，以“病理切片证据条”为唯一识别元素：由短条、标签和真实数据组成，不使用渐变或无意义装饰。图表使用 CSS 布局而非新依赖，并同步提供数值文本、状态词和 `aria-label`，不得仅依赖颜色。

覆盖 320、768、1024、1440 宽度，提供 loading、error、empty 和六种报告状态。所有操作使用原生 button 和既有键盘辅助，不增加编辑表单。
