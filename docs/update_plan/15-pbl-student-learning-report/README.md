# T15：学生 PBL 学情报告与改善轨迹

状态：仓库内实施与风险匹配的本地验收完成；全仓历史格式/覆盖率基线、真实微信真机、生产回填与部署仍未通过本任务验证。

## Summary

新增学生端“学情”主入口，以累计总览和单次 PBL 详情呈现四阶段讨论、个人薄弱点、教师发布后的两轮学习、逐项目标成绩与系统自动结论。报告从参与开始渐进更新，不计算综合分、不新增 AI 总结，也不提供结果修改入口。

## 目标

- 保留每轮自动判定依据，第二轮不得覆盖第一轮历史。
- 按当前学生与课堂聚合个人讨论和一个或多个学习计划。
- 提供学生本人可见的分页总览和单课详情 API，并保持 API/Demo 合同一致。
- 用文本可读的状态图、频次条、目标对照和时间线呈现改善过程。
- 不泄漏其他学生诊断、答案、rubric、模型提示或隐藏病例事实。

## 非目标

- 不合并普通问答报告和独立病例训练画像。
- 不改变 T14 自动判定阈值、教师审阅发布职责或 Coze schema v3。
- 不生成新的 AI 学情总结，不引入综合分或学生自评。
- 不执行生产迁移、真实微信真机、外部 Coze 或生产部署。
