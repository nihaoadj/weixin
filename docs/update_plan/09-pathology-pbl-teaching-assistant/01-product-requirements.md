# 产品最低要求与完成定义

> T09 锁定更新：首版面向医学本科生，目录固定为 `pathology-general-v1`（细胞损伤与适应、炎症、修复、循环障碍、肿瘤），并保留既有 `internal-medicine-v1`。学生和教师可见相同的薄弱分析；建议题和供应商元数据仅教师可见。建议题仅限开放讨论题，必须经教师编辑（可选）和显式采用发布，AI 不得自动发布。

本文中的“必须”均为 T09 最小范围，不能降级为可选项。

## 角色与课堂流程

1. 教师创建或选择一个病理学 PBL 课堂会话，明确班级/学生范围和讨论主题。
2. 学生在该会话中输入自己不懂的问题。AI 结合本轮经授权的有限历史回答，并用逐步追问而非一次性结论收集判断所需证据。
3. 当证据不足时，AI 明确继续追问；证据足够时，输出知识薄弱点和诊断思路问题。系统不得把“学生提出了某问题”直接等同于“学生没有掌握该知识点”。
4. AI 针对每个薄弱处生成一个或多个可供课堂使用的问题，并说明题目目标及其与薄弱处的对应关系。
5. 服务端把分析和建议题持久化到对应教师的建议队列。教师只能看到自己负责班级/学生的数据。
6. 教师可查看依据摘要、修改题目、选择发布范围，并以一次明确的“采用并发布”动作创建正式题目。发布后学生通过现有题目入口看到题目。

## 结构化诊断的最低内容

- 面向学生的教学回复，以及必要时的下一条追问。
- `knowledge_gaps`：知识点编码/名称、缺口描述、去标识化依据摘要、置信度或“证据不足”状态。
- `reasoning_issues`：诊断推理阶段、问题类型、依据摘要和改进方向。至少能区分信息收集、问题表征、鉴别诊断、证据权衡、检查选择和诊断收敛。
- `recommended_questions`：题干、教学目标、关联薄弱处、题型、可选说明/参考要点和建议发布范围。
- 安全提示、模型/fallback 状态和可追踪但不含敏感原文的版本元数据。

原始对话全文不得为了教师队列而复制一份。教师界面默认展示最小必要的依据摘要；是否查看更多上下文必须经过权限校验和明确产品决定。

## 教师采用语义

“直接采用”指教师无需复制粘贴，能够从建议详情发起采用并发布；允许在发布前编辑。该动作必须：

- 由教师显式触发，AI 不能自动发布；
- 复用现有正式题目及可见性规则；
- 保存建议题 ID 到正式题目 ID 的来源关系；
- 对重复点击、网络重试和并发请求保持幂等，不能重复创建/发布；
- 在失败时保持建议可重试，并返回明确错误，不能静默切换 Demo。
