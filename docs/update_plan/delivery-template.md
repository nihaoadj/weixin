# 工程变更交付模板

用于功能变更的计划交付记录；按适用项填写，不复制无关空字段。普通维护在回复中记录范围、检查命令和退出码即可。详细要求见[工程工作流](../development.md)。

```text
任务与范围：
工作树、分支、起始基线与已有改动保护：

当前事实：
- 已核实的文件、行为和证据：
- 公开接口/API-Demo/权限/数据/迁移影响：

计划目标：
- 待实现或待验收内容、完成条件与外部阻塞：

实施结果：
- 修改、兼容与生成物同步：

验证证据：
- 命令、目录、时间、退出码、检查范围：
- 小程序构建、逻辑、真实交互与必要截图审阅分别记录：
- 适用时记录 Demo 模式/watcher、开发目录、普通编译、角色/入口：
- 未执行项、原因与解除条件；真机按本次任务约定记录：
- 工具阻塞的人工待验编号及发布影响（见 docs/manual-acceptance.md）：

风险与回退：
最终状态及仍需完成的工作：
```

模板不扩展任务授权，也不把 Demo、本地或历史证据转换为真实服务、医学审核或生产结论。

工具/环境阻塞登记人工台账后不阻断计划收尾；实际缺陷和必要测试失败仍须处理。无需重复通过项，人工操作流程只在台账维护。
