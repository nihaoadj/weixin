# T12：PBL 前端流程与流畅度优化

状态：仓库内完成。本目录是在 T11 已落地的病理学 PBL 闭环之上优化前端展示、导航和加载反馈；不替代 T11 的交付证据。

## 目标

将学生的“课堂、任务、知识、答疑、记录”和教师的 PBL 工作区变为连续、可恢复的学习路径。优先缩短课堂到任务、教师待办到发布、任务完成到核验的操作距离，并避免切换主工作区时的整页重启。

## 非目标

- 不修改 FastAPI 路由、OpenAPI、数据模型、迁移、权限范围或 AI 提供方。
- 不新增真实模型调用、Coze 调用、外部账号、医学内容或持久化键。
- 不自动发布教学题目；教师采用发布操作保持原有服务端事务和权限校验。
