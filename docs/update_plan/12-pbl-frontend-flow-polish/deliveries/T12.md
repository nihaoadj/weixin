# T12 实施证据

状态：仓库内完成；微信真机与生产发布仍是外部验收项。

## 当前事实

T11 的 PBL 闭环和开发环境配置已存在；本轮只优化前端表现、切换和加载体验。开始前工作区已有未提交改动，均予以保留。

## 已完成范围

- 新增复用的学生主导航外壳；PBL 课堂、学习任务、知识与记录页面均可在安全区上方稳定访问五个主入口。答疑页保留紧邻输入框的内联导航，避免遮挡会话输入。
- PBL 课堂补充阶段、状态和目标知识点；加载与错误状态使用统一状态组件。
- PBL 任务显示计划状态、完成进度、下一项任务和“完成这一步”操作，仍经既有公开学习接口提交。
- 教师默认进入 PBL 工作区。四个工作区首次访问时挂载，后续通过 `v-show` 保留页面状态；每次切换会刷新对应队列，并保留 `?tab=` 初始深链接。
- 新增学生导航、320–1440 宽度和教师同页切换的组件与 E2E 覆盖；Demo 视觉基线已随页面布局更新并人工检查。

## 接口、数据与安全边界

未修改 FastAPI 路由、OpenAPI、数据模型、迁移、权限规则、持久化键或 AI 提供方。页面仍只通过 feature 的公开接口读取和写入数据；本轮未调用 DeepSeek、Coze 或任何外部模型服务，也未读取或输出本地环境密钥。
