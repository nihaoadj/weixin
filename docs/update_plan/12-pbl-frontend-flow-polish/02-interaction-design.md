# 交互与视觉设计

## 学生路径

1. PBL 课堂页保留本节课堂、讨论阶段和学习线索的上下文；主导航固定在安全区上方，任何对话长度下都可切换。
2. 固定导航不遮挡输入框或内容。PBL 页为其预留底部空间；中大屏限定内容宽度并保留现有响应式布局。
3. PBL 任务以计划为单位显示完成数、状态和唯一的下一项可执行任务；锁定任务说明其解锁条件。提交后的局部状态立即反馈，失败保留回答和提交标识。
4. 页面加载、空状态和错误状态保持明确下一步，不用动画延迟或网络重试掩盖失败。

## 教师路径

1. PBL 仍是默认工作区；工作区 tab 在同一页面内切换，不触发 `reLaunch` 或 `redirectTo`。
2. 工作区首次访问时挂载，后续以跨端兼容的 `v-show` 保留，返回时保持筛选、滚动和已加载数据；激活时由原组件自身刷新机制获取需要更新的信息。不得使用 uni-app 编译器不支持的 `KeepAlive`。
3. 初次深链接 `?tab=` 继续生效；退出后角色首页规则不变。

## 可访问性和响应式

- 所有可操作元素保留原有语义、键盘激活和至少 44px 触控尺寸。
- 在 320、768、1024、1440 宽度验证无横向溢出；固定导航包含 `safe-area-inset-bottom`。
- 仅使用项目已有色彩、间距、圆角和字体令牌；不引入图片资产或新依赖。
