## 权限、脱敏与回退

- API 测试覆盖跨教师、非成员学生、退班学生、关闭课堂、学生 DTO 字段隔离、重复 `client_message_id`、revision 竞争、编辑保护、建议 supersede 和采用幂等。
- provider fixture 覆盖 Bot/Workflow 完成与 conversation 复用、interrupt、坏 JSON、普通 API 成功/超时与无跨提供方 fallback；请求仅传匿名 PBL 引用、主题、当前问题及最多 20 条去标识化历史。
- `PBL_AI_ENABLED=false` 停止新推理而不切换普通 API；已有诊断保持只读，已发布正式题继续由 content 管理。提供方或 SDK 配置改变需要重启；活动课堂与新配置不匹配时显式不可用。
