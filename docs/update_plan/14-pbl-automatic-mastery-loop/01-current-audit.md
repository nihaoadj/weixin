# 当前审计

## 已核实事实

- 起始分支为 `dev`，相对 `github/dev` ahead 2；工作树仅有既存未跟踪目录 `output/`，本任务不编辑、删除或提交该目录。
- `PblSession.phase` 是课堂共享字段，教师可通过阶段 PATCH 任意切换；`PblParticipation` 没有个人阶段状态。
- AI schema v2 不接收或返回阶段评估。`ready` 只验证消息证据数量与知识点合同，不能证明四阶段依次完成。
- 学习计划当前只有一轮。任务完成后进入 `pending_teacher`，由教师 POST verify 写入 `improved` 或 `needs_reinforcement`。
- 当前病理目录为 `pathology-general-v2`；每个知识点只有一套 practice/retest，每个推理维度只有一套微训练提示。
- 学生页面展示课堂共享阶段；教师页面包含阶段选择器、核验意见框和两个结果按钮。
- 现有 API/Demo 装配、权限范围、采用发布幂等、测试数据库安全和契约生成链已经落地，必须保留。

## 当前差距

- 阶段只是展示标签，没有约束 AI 追问目标或证据窗口，不能形成可验证的学习过程状态机。
- “需继续巩固”停在结果标签，没有自动任务、轮次上限或耗尽后的清晰出口。
- “已改善”依赖教师主观确认，没有逐项目标、缺失证据失败关闭和版本化判定依据。
- 教师同时承担内容审核和结果分流，职责边界不清；学生下一步无法由数据确定。

## 影响面

- 后端：PBL 领域、AI provider 合同、participation/snapshot 持久化、学习计划与病例重练桥接、内容目录、权限和通知。
- 数据：Alembic 0018、历史转换脚本、OpenAPI 与生成 TypeScript 合同。
- 前端：PBL 公共接口、API/Demo adapter、学生课堂与任务列表、教师工作台。
- 验证：数据库迁移安全、契约、权限/隐私、API/Demo E2E、H5/微信构建和秘密扫描。

## 外部阻塞

真实 Coze schema v3 联调、微信真机、医学专家审核与生产部署必须由有权环境另行验收；仓库内完成不能替代这些证据。
