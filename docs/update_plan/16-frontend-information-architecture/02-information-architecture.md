# 信息架构与跳转矩阵

## 学生端一级导航

| 标签 | 路由              | 单一职责                           |
| ---- | ----------------- | ---------------------------------- |
| 课堂 | `studentPbl`      | 当前 PBL 课堂、个人阶段和讨论      |
| 学习 | `studentLearning` | 下一项任务、训练计划和训练资源入口 |
| 学情 | `studentInsights` | 薄弱点、两轮改善和系统结论         |
| 答疑 | `studentChat`     | 自由/主题问答和问答历史入口        |

`StudentTab` 与 `StudentPrimaryRoute` 只包含上述四项。`studentCases` 路径保留，但作为“学习”的二级资源页；该页底部导航仍将“学习”标为当前项。

## 学习内资源

训练资源页通过 `view=cases|knowledge|questions` 切换三个互斥视图：

- `cases`：继续中的病例、推荐病例和最近训练报告；
- `knowledge`：病理知识地图及知识巩固入口；
- `questions`：PBL 讨论题和其他已发布练习。

参数不存在或非法时使用 `cases`。页内切换只更新本地状态，不重新请求已成功加载的数据；从学习页进入时通过 `goDetail` 携带目标视图。

## 学生跳转规则

| 来源                 | 目标                  | 方法                          | 返回兜底         |
| -------------------- | --------------------- | ----------------------------- | ---------------- |
| 四个一级入口之间     | 对应一级页            | `goPrimary` / `reLaunch`      | 不保留旧一级栈   |
| 学习 → 训练资源      | `studentCases?view=…` | `goDetail`                    | 学习             |
| 训练资源 → 病例/问题 | 训练或详情页          | `goDetail`                    | 训练资源及原视图 |
| 连续病例步骤         | 训练 ↔ 报告           | `goReplace`                   | 训练资源         |
| 学情 → 单课详情      | 学情详情              | `goDetail`                    | 学情             |
| 学情行动             | 课堂或学习            | `goPrimary`                   | 对应一级页       |
| 答疑 → 历史/报告     | 二级页                | `goDetail`                    | 答疑             |
| 微训练/计划/复盘     | 对应流程页            | `goDetail` 或既有 `goReplace` | 学习             |

所有详情页继续使用 `backOrRoute`/`handleBackPress`；不得直接调用 `uni.navigate*`。快速重复点击继续由平台导航的 pending target 去重。

## 教师端工作区

| 标签 | 兼容 key   | 内容                                 |
| ---- | ---------- | ------------------------------------ |
| 待办 | `overview` | 报告待批阅、医学审核、班级和管理入口 |
| 学情 | `reports`  | 问答报告列表及教学学情入口           |
| 内容 | `problems` | 问题、病例、知识卡与审核工具         |
| PBL  | `pbl`      | 课堂、阶段分布、诊断建议和只读结果   |

工作区仍在同一页面内切换并保留已挂载状态。既有 `?tab=` key、报告详情和内容详情的返回参数不变；只修改可见标签和入口组织。
