# T16：前端信息架构、导航与页面空间优化

状态：仓库内实施完成，自动化与视觉验收证据见交付记录；微信真机仍为外部验收项。

## Summary

学生端主导航由五项收敛为 `课堂｜学习｜学情｜答疑`，原“知识”降为学习内的训练资源；教师端保留四个工作区并改为 `待办｜学情｜内容｜PBL`。微信/H5 原生标题栏作为唯一可见页面标题，正文首屏直接展示当前状态、下一步行动和核心内容。

## 目标

- 建立不超过四项的角色主导航，并保持一级、二级和连续流程跳转语义一致。
- 删除原生标题与正文大标题的重复，减少移动端首屏非业务占高。
- 重排课堂、学习、学情、答疑和教师工作区，使下一步行动优先于说明性内容。
- 保持 API/Demo、后端接口、数据、权限、PBL 自动判定和学情报告合同不变。
- 覆盖 H5 与微信构建、320–1440 宽度、键盘操作和安全区。

## 非目标

- 不新增后端路由、OpenAPI 字段、数据库迁移、持久化键或 AI 调用。
- 不修改 T14 自动判定规则、教师发布职责或 T15 报告口径。
- 不删除既有页面路径，不破坏已有深链接。
- 不引入字体、图片、图表库、路由库或其他运行时依赖。
