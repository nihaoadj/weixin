# 页面布局与标题规范

## 视觉方向

产品面向病理学 PBL 学生和教师，采用“临床学习工作簿”而非通用仪表盘：

- 颜色只使用现有 `--med-*` 海军蓝、医学青、纸张色和语义状态令牌；
- 中文正文/标题使用现有系统字体，证据标签和短状态使用现有 utility 字体；
- 卡片保持薄边框、低阴影和现有圆角，不使用渐变或装饰插图；
- 学情页的病理切片证据条是唯一强识别元素，其他页面不复制该装饰；
- 有真实顺序的阶段、任务和时间线才使用编号或轨迹标记。

## 标题规则

1. `pages.json` 原生标题是一级页面唯一可见页面名。
2. 一级页面正文不得重复原生标题或使用仅作装饰的英文眉题；根节点以 `aria-label` 或视觉隐藏标题提供可访问名称。
3. 详情页原生栏使用通用类别，正文可显示病例名、学生名或任务名等具体对象标题。
4. loading/error/empty 的 `MedState.title` 是互斥状态说明，不算重复页面标题。
5. 可见内容从“当前状态/下一步”或第一个业务分区开始；分区标题必须描述内容而非重复页面名。

## 页面布局

### 学生课堂

```text
原生标题：PBL 课堂
课堂选择器 + 当前阶段/状态
病例上下文
讨论记录
诊断线索 / 缺失要素
输入区或完成后的学习行动
四项主导航
```

移除正文 Hero；“查看课后任务”只在已形成诊断或讨论完成时出现。

### 学习

```text
原生标题：学习
下一步：PBL 或个性化任务
待完成任务/当前计划
自主训练：病例｜知识｜练习
能力依据与站内提醒
四项主导航
```

刷新动作放在对应任务分区内，避免独立大标题栏。首次使用状态仍提供进入病例训练和答疑的明确行动。

### 学情与答疑

- 学情直接从“当前重点”证据卡开始，再显示闭环分布、重复目标和最近记录；移除“我的病理学习档案”大标题。
- 学情详情移除正文中的重复返回按钮；病例名作为具体对象标题保留。
- 答疑顶部压缩为一行会话状态、主题、历史和退出工具；消息区和输入区获得剩余高度。

### 训练资源

原生标题为“病例与练习”。紧凑页内选择器显示“病例｜知识｜练习”，一次只渲染当前分组；安全说明使用单行提示。页面保留四项主导航且激活“学习”。

### 教师工作台

原生标题固定为“教师工作台”。正文顶部只保留当前工作区的一行上下文和退出操作；PBL 组件删除“PBL 教学工作区”重复标题并从“准备课堂”开始。移动端底部四项、桌面端左侧四项。

## 响应式与可访问性

- 320–599：单列、底部安全区导航、44px 最小操作区；
- 600–899：增加内容留白但保持底部导航；
- 900–1440：教师使用左侧导航，学生使用居中底部导航，内容宽度保持现有限制；
- 当前项同时使用文字、颜色和 `aria-current`；页内分组使用 `aria-pressed`；
- 键盘可激活所有按钮，焦点样式和 reduced-motion 继续使用全局令牌；
- 不允许横向滚动、导航遮挡输入框或底部内容。
