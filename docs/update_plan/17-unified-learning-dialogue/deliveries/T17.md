- S1 数据、权限与查询：新增 `20260907_0020`，回填历史 PBL 为 `classroom + guided`；支持学生发起会话、班级归属、创建幂等键和方式固定。降级在存在主动会话或非 `guided` participation 时拒绝执行。

- S4 前端、导航与兼容：学生主导航为“研讨、学习、学情”；研讨页提供课堂启动与学生主动研讨（班级、知识点、方式）并在开始后只呈现一条统一消息/阶段/诊断/后续任务流。旧答疑页仅只读历史，带主题和可编辑首问续开新研讨；旧深链接继续有效。
- S5 文档：架构、数据层、数据库、模块图和安全文档已经补充 T17 当前实现边界；OpenAPI、生成类型和视觉快照随合同/UI 更新。
