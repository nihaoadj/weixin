# T17：统一学习研讨与 PBL 闭环

状态：仓库内实施和验证完成；真实 Coze 联调、真机和生产验收仍为外部项。

## Summary

以现有 PBL 阶段、结构化诊断、教师采用发布、两轮巩固和学情报告作为唯一学习闭环。学生在每次参与开始时选择 `guided` 或 `direct` 沟通方式；方式只改变 AI 回复策略，不改变证据门槛和后续流程。

学生主动研讨必须关联有效班级并预选同一病理主题下 1～3 个知识点。旧自由问答和报告只读保留，可携带主题和可编辑首问续开新研讨，但旧内容不作为新诊断证据。

## 目标

- 学生主导航收敛为“研讨、学习、学情”，研讨成为唯一新对话入口。
- 教师课堂与学生主动会话共享 participation、消息、schema v4 诊断、建议队列和学习计划。
- `guided` 以追问引导，`direct` 先解释再检查理解；两者都必须取得当前阶段的学生证据。
- 新接口、API/Demo adapter、迁移、权限、生成契约和回归证据同步交付。

## 非目标

- 不把旧自由问答自动转换为诊断、建议题或学习计划。
- 不改变教师显式采用发布、两轮阈值和系统自动判定规则。
- 不真实调用 Coze、不迁移生产数据库、不部署、提交或推送。
- 不重命名后端 PBL 模块或复制第二套 learning/dialogue 业务实现。
