# WX Frontend Quality Bar

Project layout, interaction and accessibility rules live in [UI](../../../../docs/ui.md). Read only the relevant sections; do not duplicate them here. Adaptations retain their [pinned sources and licenses](sources.md).

Before delivery, assess the affected state: can the user identify the next action, distinguish student/AI/system/teacher evidence, and finish with long content, no data, failure or keyboard focus? Resolve observed defects within scope and report missing runtime evidence under [verification](verification.md).
