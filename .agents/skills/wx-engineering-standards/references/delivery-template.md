# 工程变更交付模板

复制本模板到对应交付记录（或在 PR/任务说明中逐项填写）。所有“当前事实”和“计划目标”必须分开；未知项保留为未知，不用推测补齐。

```text
任务/改动范围：
负责人/接收者：
工作树路径：
起始基线：commit；已有工作区改动摘要；目标文件编辑前 SHA-256（如适用）

当前事实（本次 checkout 已核实）：
- 受影响路径、模块和公开接口：
- API/Demo、权限、数据和迁移影响：
- 已存在的命令/配置及安全前置条件：

计划目标（尚未实现或尚未验收）：
- 相关 T01–T07 目标、待接收输入或目标命令：
- 不能据此宣称已通过的门槛：

实施结果：
- 修改文件及兼容性说明：
- 生成契约、迁移、测试或文档是否需要同步：

验证证据：
- 命令、执行目录、时间、退出码：
- 测试数/覆盖率范围/证据路径：
- 未执行项、原因、风险和解除条件：
- 纯文档：Markdown 格式、相对链接、命令/路径存在性、`git diff --check`：
- 分层改动：前端 `node scripts/frontend-boundaries.mjs`、后端 `python backend/scripts/check_boundaries.py`（若适用）：

安全与回退：
- 权限、敏感数据、日志、外部调用检查：
- 回退步骤及数据影响：

状态：未开始／进行中／仓库内完成但外部阻塞／全部完成
接收者复验步骤：
```

本模板不授权提交、推送、部署、密钥轮换、生产数据库操作或修改全局设置。
