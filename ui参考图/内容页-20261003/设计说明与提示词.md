# 教师端内容页 UI 参考

使用内置 image_gen 生成。当前仅为视觉方案，未修改运行代码；资源、数量与插画均为设计示例。

参考：教师端-20261002/03-内容.png、学情/02-学情-最终参考-01-总览.png、PBL完成研讨版-20261002/10-PBL首页最终版.png。

- A：分类页签、状态筛选、单列资源记录，适合检索与编辑，建议作为实施基础。
- B：四类资源入口、双列主题卡片，适合资源浏览。
- C：按草稿、医学审核、待发布、已发布分组，适合维护与发布管理。

统一冰蓝背景、深蓝标题、青色强调及 PBL / 学情 / 内容 三项导航。分组计数、最近发布等新增呈现为设计建议，实施时需确认数据支持与范围。
